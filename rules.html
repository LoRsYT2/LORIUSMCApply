EGOMC Rules

These are the general rules of the EGOMC server

The rules listed here apply to both the Minecraft server and the Discord server

If any changes are made to the rules, this page will be updated

1

Advertising hacked clients / cheating

Advertising any hacked client or encouraging cheating is strictly prohibited.

120-Day Ip Ban

2

Advertising other server domains

Sharing other server addresses in-game or on Discord is not allowed.

120-Day Ip Ban

3

Ban Evading

Using an alternate account to join after being banned is not allowed. The ban will be extended and additional punishments applied.

14-Day Ip Ban

4

Bug Exploiting

If you discover a bug or exploit, report it immediately. Exploiting may lead to a ban.

First: 7-Day Ip Ban,
Second 14-Day Ip Ban,
Third 30-Day Ip Ban.

5

Chargeback

Requesting a chargeback on purchases will result in a ban.

Permanent Ip Ban

6

Threats

All threats, whether personal information exposure or DDoS threats, are prohibited.

Personal threats
30-Day Ip Ban
DDoS threats
Permanent Ip Ban

7

Discrimination

Discrimination against any player based on race, religion, gender, orientation, or needs is prohibited.

5-Day Ip Mute

8

Disrespect / Bullying

Insults, bullying, or harassment are not allowed.

12-Hour Mute

9

Inappropriate Buildings

Building or placing signs containing offensive or explicit content is not allowed.

Warning -> 3-Day Ban

10

Inappropriate Minecraft Usernames

Offensive or sexual usernames are not allowed. Repeated violations may result in a ban.

Permanent Ban

11

Inappropriate Nicknames

Using offensive nicknames or impersonating staff ranks is not allowed.

Warning -> 5-Day Ban

12

Inappropriate Skins / Capes

Skins or capes containing offensive or sexual content are not allowed.

Kick -> 3-Day Ban

13

Light Advertising

Hinting at your own server, channel, or content in public chat is not allowed.

4-Hour Mute

14

Mute Evading

Using another account to bypass a mute is not allowed.

5-Day Ip Mute

15

Spamming

Sending repeated or identical messages in a short time is not allowed.

2-Hour Mute

16

Chat Flooding

Using repeated characters or flooding chat with identical messages is not allowed.

Warning -> 1-Hour Mute

17

Spamming Commands

Repeatedly sending the same commands (like /tpask, /pay, etc.) is not allowed.

Kick -> 3-Day Ban

18

Swearing

Excessive use of profanity is not allowed.

2-Day Mute

19

Inappropriate Links

Sharing adult or offensive content links is not allowed.

5-Day Ip Mute

20

Cheating / Blacklisted Modifications

Using tools that give unfair advantages (AutoClickers, Macros, etc.) is not allowed.

30-Day Ip Ban

21

Racism

Any racist behavior will result in strict punishment up to a permanent ban.

First: 60-Day Ip Ban,
Second 90-Day Ip Ban,
Third Permanent Ip Ban.

22

Malicious Links

Links intended to steal accounts or install malware are prohibited.

Permanent Ip Ban

23

Scamming

Any attempt to scam other players is not allowed.

First: 7-Day Ip Ban,
Second 30-Day Ip Ban,
Third Permanent Ip Ban.

24

IRL Trading

Selling accounts or items for real money is strictly prohibited.

Permanent Ip Ban

25

Encouraging Rule Breaking

Encouraging others to break rules is not allowed.

Warning -> 7-Day Ip Ban

26

Stats Boosting

Using alternate accounts to boost stats or rewards is not allowed.

14-Day Ip Ban

27

Staff Impersonation

Impersonating staff names or ranks is not allowed.

3-Day Ban
Permanent Ban

28

Falsifying Evidence

Editing screenshots or creating fake transactions to mislead is not allowed.

7-Day Ip Ban

29

AFKing in Trade Rooms

Staying AFK in trade rooms to hold a spot is not allowed.

Kick -> 1-Hour Ban

Appeals & Support
